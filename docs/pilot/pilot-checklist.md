# Pilot Checklist

## Before Session (Instructor)

- [ ] `/admin/pilot-check` all green or acceptable warnings
- [ ] Admin login verified
- [ ] Session created with correct name
- [ ] Join code/URL copied
- [ ] Test join from second browser/device
- [ ] WebSocket connected on admin dashboard
- [ ] Event Studio / World accessible (if using)

## During Session (Instructor)

- [ ] All teams joined
- [ ] Game started
- [ ] Step timer visible
- [ ] Monitor submit rate each step
- [ ] Breaking news tested (if using)
- [ ] Pause/resume tested once

## Learner Instructions (Share verbally or slide)

- 참가 코드로 `/join` 접속
- 팀명 정확히 입력
- 각 Step: 체크리스트 확인 → 검증 → 제출
- 제출 후 대기 — GM이 다음 Step 진행
- GM/관리자 링크 클릭하지 않기

## Fallback Operations

- WebSocket failure: manual refresh; GM continues from control panel
- AI unavailable: manual events only
- Single team device issue: GM zero submit after timeout

## Post-Pilot Feedback to Collect

- Step clarity (1–7)
- Checklist usefulness
- News/event impact understanding
- Financial dashboard readability
- Technical issues (disconnect, login, submit errors)
- Session length vs. planned duration
