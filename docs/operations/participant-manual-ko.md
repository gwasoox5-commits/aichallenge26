# 제조 경영 시뮬레이션 — 참가자 운영 설명서

> **대상**: CEO(팀 대표) 및 팀원  
> **목적**: 가상 제조 기업의 경영 의사결정을 반기별 7단계로 수행하며, 재무·운영·시장 환경 변화에 대응하는 경험

---

## 1. 시뮬레이션이 무엇인가

여러분은 **한 팀 = 한 제조 기업**을 운영합니다. 각 **반기**(6개월)마다 아래 순서로 의사결정을 내립니다.

1. 자금을 조달하고  
2. 설비에 투자하고  
3. 인력을 채용한 뒤  
4. 원재료를 구매하고  
5. 제품을 생산하고  
6. 시장에 판매합니다.  
7. 마지막 단계에서는 **결산**이 진행됩니다(팀 입력 없음).

게임은 보통 **1~3년(2~6반기)** 로 진행됩니다. 화면 상단에 `1년차 전반기`, `2년차 후반기`처럼 표시됩니다.

**목표**: 현금 흐름·수익성·성장을 균형 있게 관리하며, 경영 환경(뉴스·시장 변화)에 맞는 전략을 세우는 것입니다.

**통화 단위**: 화면의 모든 금액은 **만원**입니다. (예: 10,000 = 1억 원)

---

## 2. 입장 방법

### 2-1. 참가 코드로 입장

1. 강사가 안내한 **참가 URL** 또는 `/join` 페이지에 접속합니다.  
2. **참가 코드**(5자, 영문·숫자)를 입력하고 **세션 확인**을 누릅니다.  
3. 세션 이름·현재 반기·진행 단계가 맞는지 확인합니다.  
4. **팀명**을 입력합니다(팀당 하나, 중복 불가).  
5. **입장하기**를 누르면 자동으로 플레이 화면(`/play`)으로 이동합니다.

> URL에 코드가 포함된 경우(`?code=XXXXX`) 코드가 자동 입력될 수 있습니다.

### 2-2. 자주 나오는 오류

| 메시지 | 대처 |
|--------|------|
| 참가 코드를 찾을 수 없습니다 | 코드 재확인 |
| 이미 종료된 세션입니다 | 강사에게 문의 |
| 이미 사용 중인 팀명입니다 | 다른 팀명 사용 |
| 참가 정원이 모두 찼습니다 | 강사에게 문의 |

### 2-3. 팀 구성 권장

- **1팀 = 1명이 화면에서 제출**(CEO 역할)하는 것을 권장합니다.  
- 나머지 팀원은 토론·자료 정리·전략 수립에 참여하고, CEO가 최종 입력·제출합니다.

## 3. 플레이 화면 구성

### 3-1. 상단 헤더

| 요소 | 의미 |
|------|------|
| 팀명 | 우리 팀 이름 |
| N년차 전/후반기 | 현재 게임 기간 |
| N단계 · … | 지금 해야 할 Step |
| 남은 시간 (M:SS) | 현재 Step 제한 시간 |
| 제출 완료 | 이번 Step을 이미 제출한 상태 |
| 미확인 뉴스 | 아직 확인하지 않은 경영 뉴스 수 |
| 연결 상태 | 실시간 동기화 연결 여부 |

### 3-2. 메인 영역 (왼쪽)

| 영역 | 설명 |
|------|------|
| **CEO 명령 대시보드** | 지금 할 일, 현금·재고 요약, 경제 환경·활성 이벤트 요약 |
| **Step 진행 스테퍼** | 1~7단계 중 어디까지 왔는지 (완료/진행/대기) |
| **학습 패널** | Step별 학습 목표·체크리스트 (**제출 전 전체 체크 필수**) |
| **Step 입력 폼** | 현재 Step에 해당하는 입력 화면 |
| **입찰·낙찰 현황** | Step 4·6 이후, 지역별 입찰/낙찰 결과(확정 전·후) |
| **검증 결과** | 「검증」 실행 후 규칙 통과/실패 내역 |
| **Journal(분개)** | 의사결정에 따른 회계 분개 내역 |

**제출 완료 후**에는 입력 폼 대신 **대기 패널**이 표시됩니다. 다음 Step이 열릴 때까지 수정할 수 없습니다.

### 3-3. 사이드바 (오른쪽)

| 영역 | 설명 |
|------|------|
| **지역 브랜치 지도** | 7개 지역(유럽·아시아·중동·아프리카·오세아니아·북미·남미) 개설·활동 상태 |
| **경영환경 뉴스** | 시장·경제 관련 뉴스 목록 |
| **시장 이벤트 피드** | 경제 지표 변화, 예정된 변경, 활성 이벤트 |

### 3-4. 하단 재무 패널

| 영역 | 설명 |
|------|------|
| **Dashboard** | 현금, 재고, 생산·판매 실적, ROE/ROA, 부채비율, 경제지수 |
| **손익계산서(P/L)** | 매출, 원가, 판관비, 순이익 |
| **재무상태표(B/S)** | 자산, 부채, 자본 |

### 3-5. 뉴스

- 상단 **Breaking 배너** 또는 사이드바 **경영환경 뉴스**에서 확인합니다.  
- 새 뉴스가 오면 창이 열릴 수 있습니다. 내용을 읽고 **「확인했습니다」** 를 눌러 주세요.  
- 뉴스는 의사결정(원가, 수요, 금리 등)에 영향을 줄 수 있습니다.

## 4. Step별 진행 방법

### 공통 절차 (Step 1~6)

1. **학습 패널** 체크리스트를 모두 체크합니다.  
2. 입력 폼에 값을 넣습니다.  
3. (권장) **검증** 버튼으로 규칙 위반 여부를 확인합니다.  
4. **제출** 버튼을 누릅니다.  
5. 「제출 완료」가 표시되면 **다음 Step이 열릴 때까지 대기**합니다.

> 제출 후에는 해당 Step을 수정할 수 없습니다.

---

### Step 1 · 자금조달

**목적**: 반기 운영에 필요한 자금을 조달·배분합니다.

**입력 항목**

| 구분 | 항목 | 단위·참고 |
|------|------|-----------|
| 1A 연초 | 연초 차입 | **천만원** 단위 (1 = 1,000만원) |
| 1A 연초 | 예금 | 천만원 |
| 1B 연중 | 연중 차입 | 천만원, **최대 1억(10,000만)** |
| 1B 연중 | 부채 상환 | 만원 |

**주요 규칙**

- 연초 차입은 **자기자본 이하**만 가능  
- 연중 차입은 **1억 이하**  
- 모든 결정 후 **현금은 0 미만 불가**  
- 상환액은 **기존 부채 + 이번 반기 신규 차입**을 넘을 수 없음  

**금리(결산 시 반영)**: 차입 약 10%/년, 예금 약 5%/년

---

### Step 2 · 설비투자

**목적**: 토지·생산 설비를 확장해 생산 능력을 키웁니다.

| 항목 | 비용 | 효과 |
|------|------|------|
| 토지(필지) | 3,000만/필지 | **최대 4필지** |
| Big 기계 | 600만/대 | 생산 30/대/반기, 가동비 80만 |
| Small 기계 | 300만/대 | 생산 10/대/반기, 가동비 40만 |

**주요 규칙**

- 필지당 기계 슬롯: Big×2 + Small ≤ 필지×4  
- Big ≤ 필지×2, Small ≤ 필지×4  
- 총 투자액 ≤ **보유 현금**  

**생산능력(참고)**: Big×30 + Small×10 (반기)

---

### Step 3 · 인력채용

**목적**: 구매·생산·영업 부서 인력을 배치합니다.

| 부서 | 1인당 처리량/반기 | 용도 |
|------|-------------------|------|
| 구매 | 30 | Step 4 원재료 구매량 상한 |
| 생산 | 10 | Step 5 생산량 상한 |
| 영업 | 10 | Step 6 판매량 상한 |

- **인건비**: 약 300만/인/반기 + 복리후생 15% (결산 시 반영)  
- **1년차**: 퇴사·부서 전환(구조조정) **불가**  
- **2년차부터**: 퇴사·부서 간 전환 가능  

---

### Step 4 · 원재료구매

**목적**: 지역별로 원재료를 입찰·구매하고, 필요 시 **구매 브랜치**를 개설합니다.

**7개 지역**

| 지역 | 브랜치 개설비 | 재료 단가(참고) | 지역 구매 한도 |
|------|---------------|-----------------|----------------|
| 유럽 | 500만 | 24 | 300 |
| 아시아 | 300만 | 12 | 600 |
| 중동 | 150만 | 15 | 400 |
| 아프리카 | 100만 | 10 | 500 |
| 오세아니아 | 150만 | 18 | 300 |
| 북미 | 500만 | 21 | 500 |
| 남미 | 200만 | 16 | 300 |

(단가·한도는 기본값이며, 경제 환경에 따라 변동할 수 있습니다.)

**지역·브랜치 규칙**

- 해당 지역에서 **처음 구매**하려면 **구매 브랜치 개설**이 필요합니다(개설비 발생).  
- **구매 브랜치**를 연 지역은 **별도 판매 브랜치 없이 판매**도 가능합니다.  
- **이번 반기에 실제 구매(수량>0)하는 지역 수**  
  - 1년차: **최대 3개**  
  - 2년차: **최대 4개**  
  - 3년차: **최대 5개**  
- **원재료 4단위 = 완제품 1개** (BOM)  
- 물류비: 재료 **5만/단위**  
- 입찰 단가가 **낮을수록** 해당 지역 물량 배분에 유리합니다(전 팀 제출 후 시장 배분).

**주요 규칙**

- 총 구매량 ≤ **구매 인력 Capacity**  
- 총 비용 ≤ **현금**  

---

### Step 5 · 생산

**목적**: 보유 원재료와 설비·인력으로 완제품을 생산합니다.

| 입력 | 설명 |
|------|------|
| 생산량 | 만들 완제품 개수 |
| Big/Small 가동 대수 | 보유 대수 이하 |

**최대 생산량** = 다음 중 **최솟값**

- 보유 원재료 ÷ 4  
- Big가동×30 + Small가동×10  
- 생산 인력×10  

기계 가동비·탄소세(경제 환경) 등이 비용에 반영됩니다.

---

### Step 6 · 판매

**목적**: 지역별로 판매 가격·수량을 입찰하고, 필요 시 **판매 브랜치**를 개설합니다.

**지역·브랜치 규칙**

- **구매 브랜치**가 있는 지역은 판매 브랜치 없이 판매 가능.  
- 판매만 하려면 **판매 브랜치 개설**(지역별 개설비) 필요.  
- **판매 활동 지역 수**: 1년차 3 / 2년차 4 / 3년차 5 (Step 4와 동일 cap)  
- **판매 전용 브랜치** 개수도 연도별 cap 적용  
- 물류비: 제품 **10만/단위**  
- 입찰 **가격이 낮을수록** 판매 배분에 유리  

**주요 규칙**

- 지역별 판매가 ≤ 지역 **최대 판매가**  
- 지역별 수량 ≤ 지역 **판매 한도**  
- 총 판매량 ≤ **영업 인력 Capacity**  
- 총 판매량 ≤ **완제품 재고**  

---

### Step 7 · 결산

**팀 입력 없음.**

- 화면에 결산 대기 안내가 표시됩니다.  
- 반기 **결산이 완료**되면 이자·감가·법인세 등이 반영되고, P/L·B/S가 확정됩니다.  
- 다음 반기 Step 1부터 다시 진행합니다.

---

## 5. 시장·입찰 이해하기

### Step 4 (구매) · Step 6 (판매)

- 모든 팀이 제출한 뒤, 지역별로 **입찰 경쟁**이 이루어집니다.  
- **구매**: 단가 **↑** 우선 / **판매**: 단가 **↓** 우선  
- **입찰·낙찰 현황** 패널에서 우리 팀 결과를 확인할 수 있습니다.  
- Step이 넘어가기 전에는 **예상** 결과, 넘어간 후 **확정** 결과가 표시될 수 있습니다.

### 경제 환경 변화

- 사이드바 **시장 이벤트**·**경제 영향**에서 원자재 가격, 수요, 금리 등 변화를 확인하세요.  
- 「경제 환경이 변경되었습니다」 배너가 뜨면 **확인** 후 전략을 조정하세요.

---

## 6. 게임 진행 중 알아두기

| 상황 | 화면/행동 |
|------|-----------|
| Step 제한 시간 | 헤더 카운트다운 — 시간 내 제출 권장 |
| 제출 완료 후 | 다음 Step까지 대기, 토론·전략 검토 |
| 일시정지 | 「제출 불가」 안내 — 강사 재개까지 대기 |
| Step 잠금 | 추가 제출 불가 — 강사 안내 따르기 |
| 연결 끊김 | 새로고침, 네트워크 확인 |

## 7. 초기값·핵심 숫자 요약

| 항목 | 값 |
|------|-----|
| 시작 현금·자기자본 | 10,000만 (1억) |
| 토지 | 최대 4필지, 3,000만/필지 |
| BOM | 원재료 4 → 완제품 1 |
| 활동 지역 수(구매·판매) | Y1: 3 / Y2: 4 / Y3: 5 |
| 구조조정 | 2년차부터 |
| Step 수/반기 | 7 (마지막은 결산, 입력 없음) |

## 8. 자주 묻는 질문

**Q. 제출을 잘못했어요.**  
A. 제출 후에는 수정할 수 없습니다. 팀 내에서 다음 Step부터 전략을 조정하세요.

**Q. 검증은 꼭 해야 하나요?**  
A. 필수는 아니지만, 제출 전 검증으로 규칙 위반을 미리 확인하는 것을 권장합니다.

**Q. Journal·재무제표는 언제 갱신되나요?**  
A. Step 제출·결산·경제 이벤트 반영 시 실시간으로 갱신됩니다.

**Q. 뉴스를 안 읽어도 되나요?**  
A. 가능하지만, 시장 변화를 놓치면 Step 4·6 전략에 불리할 수 있습니다.
